# Radio

A minimal, high-contrast radio streaming application built with the Light Phone SDK. This tool allows users to discover, play, and curate their favourite online radio stations.

## Features
- **Live Streaming**: High-quality audio playback using Media3 ExoPlayer.
- **Background Playback**: Continues playing audio even when the tool is minimised or the screen is off.
- **Home Screen Integration**: Control playback directly from the LightOS Clock screen.
- **Station Search**: Discover thousands of stations globally via the Radio Browser community API.
- **Library Management**: Curate Favourites and track listening history.
- **Minimalist Aesthetic**: Pure monochrome design following the Light Phone III design language.
